## Context

Work tier mappings already route Claude through Bedrock, but shared settings still enable bare Claude IDs and seed Anthropic OAuth.
The user approved Bedrock-only Claude access for work while retaining OpenAI and personal profiles.

## Plan

### Scope

Change `agents/base-settings.nix` only, plus this validation record.

### Approach

1. Remove bare Claude IDs from the shared work model list and remove the direct Anthropic auth seed.
2. Validate evaluated settings and auth, run repository checks, and sync generated profiles.

### Risks

Existing mutable auth files may retain user-managed Anthropic credentials because sync preserves target-only JSON keys.
Do not modify those credentials or generated files manually.
This change removes enabled model entries, not the provider built into Pi.
